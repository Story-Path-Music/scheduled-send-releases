# 排程寄信（Thunderbird 外掛）安裝包

這裡只放安裝包。

## 安裝（Windows）

1. 下載 [scheduled-send-setup.zip](https://github.com/Story-Path-Music/scheduled-send-releases/releases/latest/download/scheduled-send-setup.zip)。
2. 解壓縮後，雙擊 `install.cmd`。如果 Windows 跳出安全警告，按「其他資訊」→「仍要執行」。
3. 關掉 Thunderbird 再打開，按右上角選單的提示同意啟用。沒看到提示，就到「附加元件與佈景主題」把「排程寄信」打開。

## 移除與升級

- 移除：在附加元件頁移除，或跑 `uninstall.cmd`（這台電腦的所有 Thunderbird 設定檔一起移除）。
- 升級：關掉 Thunderbird，下載新版，再跑一次 `install.cmd`。

需要先由管理員開通你的信箱，排程信才會寄出。
